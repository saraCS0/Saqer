# Saqer Application

This is a smart mobile application designed to assist individuals with disabilities in communicating more effectively.

## Purpose

The app helps users with communication difficulties by interpreting hand gestures or movements and translating them into voice or messages.

## Key Features

- Gesture recognition using camera input  
- Real-time response with audio or text translation  
- Accessible and user-friendly interface  
- Can be connected to caregivers or family members

## Technologies Used

- Flutter for app development  
- Python for gesture recognition logic  
- Supabase for backend and data synchronization
